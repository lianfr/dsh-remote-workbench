# DSH Remote Workbench

在 DSH 对话中连接和管理远程服务器。查看机器状态、浏览文件和使用 Slurm，都可以留在当前对话里完成。

## 功能

- **服务器连接**：读取本机 `~/.ssh/config` 中的服务器，选择后连接；也可以在界面中新建连接并保存到 SSH 配置。连接建立后，同一服务器的后续操作会复用 SSH 会话。
- **资源监控**：查看一台或多台服务器的 CPU、内存、GPU、网络、磁盘和进程；支持查看趋势、调整采样间隔，以及筛选和排序进程。
- **远程文件**：从远程用户的家目录开始浏览，支持创建、重命名、删除、上传和下载文件；文本文件在 DSH 右侧的“文件”面板中预览。
- **Slurm**：查看作业队列、分区和节点，查看作业详情与日志，提交和取消作业。操作使用 SSH 登录身份；服务器未提供 Slurm 客户端时会显示提示。

## 安装

1. 在 DSH 中打开 **插件**，选择添加插件，并使用本仓库地址：

   ```text
   https://github.com/lianfr/dsh-remote-workbench
   ```

2. 启用 **dsh-remote-workbench**。
3. 打开一个对话，在会话视图中选择 **远程服务器** 标签页。

## 开始使用

首次打开时不会自动连接服务器。点击左上角的 **选择服务器**，从本机 SSH 配置中选择目标；也可以在该菜单中新建连接。

默认进入监控页，选择服务器后会查看当前服务器的状态。如需同时比较多台机器，点击监控范围旁的服务器配置图标，选择要监控的服务器并应用。监控范围与文件和 Slurm 的操作目标分别设置。

在 **文件** 页浏览目录，打开文本文件后，预览会显示在 DSH 右侧“文件”面板中。在 **Slurm** 页可查看和管理当前服务器可见的作业。

## 运行条件

- DSH `0.2.2-alpha.2` 或更新版本。
- 本机已安装 OpenSSH，服务器已配置在 `~/.ssh/config` 中，或通过插件新建配置。
- 远程服务器运行 Linux，并可使用 Python 3。
- SSH 连接需能以非交互方式完成认证，例如通过 ssh-agent 或可直接使用的密钥。主机密钥检查、跳板和其他 SSH 配置由本机 OpenSSH 处理。
- GPU 监控依赖服务器可用的 NVIDIA 工具；Slurm 功能需要服务器提供相应的 Slurm 客户端命令。

文本预览上限为 1 MiB，单文件上传和下载上限为 32 MiB，单个目录最多显示 5000 项。
